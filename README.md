# BETBOOM LED Studio

Локальный редактор LED-бортов со сценой AIR, новым SVG-логотипом BETBOOM и ONY Track Compressed Black.

## Запуск

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. Сборка и npm для работы редактора не нужны. Шрифт, логотип и opentype.js поставляются локально. Предыдущая версия сохранена в `index.before-air.html`.

## Работа

- Во вкладке «Борт» задайте общую длину, высоту и длину секции. Выбор «Разделить поровну на» предлагает только точные делители. При ручной длине секции остаток показан отдельно. Подходящие делители видны сразу, без раскрытия списка.
- Над сценой выберите блок, чтобы редактировать его в инспекторе. Добавляйте текст и логотип, меняйте их порядок, дублируйте или удаляйте.
- «Вписать», 100% и 200% меняют только масштаб просмотра. По умолчанию режим «Стыки» показывает три повторения рядом. Развёртка всей длины убрана. Колесо мыши над сценой меняет масштаб с привязкой к указателю. Сетку и линейку можно включить отдельно.
- На телефоне при уходе основной сцены за экран появляется мини-превью выбранного блока.
- Для перемещения увеличенного макета используйте полосу прокрутки, среднюю кнопку мыши или пробел с перетаскиванием. Горячие клавиши: F вписать, 1 масштаб 100%, 2 масштаб 200%.
- Текст намеренно выходит за высоту секции. Это часть макета; автоматическое уменьшение кегля не применяется.
- Если блокам не хватает ширины, редактор показывает предупреждение и сохраняет неотрицательные промежутки. Экспорт учитывает границы секции.

## Сохранение и экспорт

Изменения автоматически сохраняются в браузере под текущим локальным адресом. Кнопка «Сохранить проект» скачивает JSON, включая загруженные пользовательские шрифты. «Открыть» восстанавливает этот файл. Поддерживаются OTF, TTF и WOFF до 5 МБ на шрифт, JSON до 20 МБ. При нехватке места для автосохранения редактор предлагает скачать проект.

«Экспорт SVG» позволяет скачать одну секцию или весь борт. Весь борт состоит из повторений секции; остаток заполняется началом следующего повторения. Размер файла указан до скачивания. SVG содержит векторные контуры и локальные ссылки внутри того же файла, без внешних шрифтов или изображений. Предупреждение по ширине не меняет макет автоматически.

Анимации относятся к интерфейсу: выбор блока, масштаб, перемещение блоков, вкладки и окно экспорта. SVG остаётся статичным. Учитывается `prefers-reduced-motion`.
