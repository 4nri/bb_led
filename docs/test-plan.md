# Проверки

Связанные файлы: `docs/plans.md`, `docs/status.md`.

## Объём

Логотип, шрифт, создание и редактирование блоков, экспорт одной секции. Проверки браузером без добавления тестового фреймворка. Публикация на GitHub Pages, разные системы рендера и физический LED-процессор в объём не входят.

## Приёмка

- [x] При запуске видны новый логотип и оффер ONY Track Compressed Black.
- [x] Размер исходного оффера 138 px, смещение 5 px; выход букв за край сохраняется.
- [x] Пропорции логотипа 500:118 сохраняются при изменении высоты.
- [x] Новый текст по умолчанию использует ONY; кириллица и цифры отображаются.
- [x] Работают дублирование, удаление и настройки обоих типов блоков.
- [x] Пользовательский шрифт можно загрузить и переключить обратно на ONY.
- [x] Скачанный SVG имеет заданные размеры, содержит контуры обоих блоков, обходится без `text`, внешних изображений и шрифтов; геометрия совпадает с превью.
- [x] Экспорт пустого баннера даёт только фон без NaN/Infinity.
- [x] Потеря файла шрифта или логотипа показывает ошибку и блокирует экспорт.
- [x] Загрузка не требует CDN.
- [x] JavaScript не содержит синтаксических ошибок, консоль без ошибок при штатной работе.
- [x] Проверены десктоп и телефон; замечания исходного интерфейса записаны в аудит.

## Команды

```sh
python3 -m http.server 8765 --bind 127.0.0.1
# Извлечённый inline-скрипт:
node --check /путь/к/извлечённому-скрипту.js
git diff --check
```

Размеры секций, отрицательные интервалы при слишком длинном тексте, сброс данных после перезагрузки и полный экспорт борта оцениваются в аудите. Эти прежние ограничения не расширяют объём текущей правки.

## AIR: новая приёмка

- [x] Девять тестов модели и геометрии: остаток, пустой макет, неотрицательные интервалы, недопустимый импорт, сериализация шрифта, полный борт, кадрирование, лимит повторений и делители.
- [x] AIR работает без сборки и внешнего CDN.
- [x] Масштаб 100% и 200% соответствует размерам SVG в CSS-пикселях; «Вписать» помещает сцену в окно.
- [x] Стыки показывают три секции с двумя границами.
- [x] Сетка, линейка, выбор, редактирование, дублирование, удаление и порядок блоков работают.
- [x] Автосохранение восстанавливает текст и пользовательский OTF после перезагрузки.
- [x] Импорт JSON восстанавливает проект; невалидный файл не меняет текущий макет.
- [x] Пустой числовой ввод не меняет геометрию и блокирует экспорт до исправления.
- [x] При ручной секции 2500 px показаны 9 полных секций и остаток 2460 px; экспорт борта содержит 10 повторений с кадрированием последнего.
- [x] Скачанный SVG секции совпадает с геометрией превью, без внешних шрифтов и изображений.
- [x] При короткой секции нет отрицательных промежутков; предупреждение видно в редакторе и экспорте.
- [x] Пустой проект экспортируется фоном; логотип можно добавить снова.
- [x] На ширине 390 px нет горизонтального переполнения страницы; увеличенный макет перемещается внутри сцены.
- [x] Переходы работают, а reduced motion отключает их; анимации не попадают в SVG.
- [x] Потеря активов блокирует экспорт с понятной ошибкой.
- [x] Нет необработанных ошибок JavaScript, пройдены синтаксические проверки и `git diff --check`.

Команды AIR: `node --test tests/model.test.mjs`, `node --check js/app.mjs`, `node --check js/model.mjs`, `node --check js/geometry.mjs`, `node --check js/project.mjs`.

Дополнительно проверены неверный JSON и OTF: текущий макет сохраняется. При прокрутке на телефоне появляется закреплённое мини-превью выбранного блока, действие «К сцене» возвращает к рабочей области.
